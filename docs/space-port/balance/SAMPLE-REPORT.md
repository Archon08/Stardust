With these **placeholder** stats the heavy Bomber is a strict-dominant build (wins

## How to read this

- A healthy matrix is a **rock-paper-scissors** triangle (no row all-green). The current
  synthetic triangle is fully transitive (Bomber > Gunship > Interceptor), i.e. a pure
  tier list — the worst case the tuner must fix with the real curves.
- The structural gate that DOES run hard (`DominantStrategyReport`) only requires the
  matrix be non-degenerate (at least one decisive >= 70% pairing), proving the combat
  math is live rather than inert.

## Plugging in real data (6.B handoff)

Replace `space_balance::archetypes()` with values read from the extracted datatables:
`ship_chassis.iff` (chassis HP, speed, yaw), `*_weapon_*` component tables
(min/max damage, refire, efficiency), `*_shield_*` / `*_armor_*` (pools + effectiveness).
Field-for-field mapping is documented in `docs/space-port/balance/README.md` and the
`BalanceShip` struct comments.
